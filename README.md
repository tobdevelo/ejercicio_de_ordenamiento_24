
# Ejercicio 24: Búsqueda en Secuencia Ordenada

**Asignatura:** Estructuras de Datos — Unidad 3 (Taller Práctico)  
**Programa:** Ingeniería de Software — Universidad de Cartagena  
**Estudiante:** Jorge Taján Acevedo  
**Tutor:** John Carlos Arrieta Arrieta

## Descripción
Implementación manual en Java de tres algoritmos de búsqueda sobre arreglos ordenados de tamaño configurable (`N = 100`, `10.000`, `1.000.000`), registrando la cantidad de comparaciones realizadas y el tiempo de ejecución en nanosegundos:
- **Búsqueda Lineal** ($O(n)$)
- **Búsqueda Binaria** ($O(\log n)$)
- **Jump Search** ($O(\sqrt{n})$)

## Instrucciones de ejecución
1. Clonar el repositorio:
   `git clone https://github.com/tobdevelo/ejercicio_de_ordenamiento_24.git`
2. Abrir el proyecto en **IntelliJ IDEA** (JDK 17 o superior).
3. Ejecutar el método `main` ubicado en `src/Main.java`.
